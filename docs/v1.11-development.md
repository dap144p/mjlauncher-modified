## Offline build
1. Keep the v10 APK plus private v10 project archive locally. NEVER push any signing key or passwords.
2. `bash patches/build-engine-v111.sh PATH_TO_V10_ASM_DEPS build/afk-engine-v111.jar`
3. `python3 patches/apply-v111-to-v10.py --base-v10 PATH_TO_V10.apk --apktool PATH_TO_APKTOOL.jar --disassemble-java patches/Disassemble.java --agent-jar build/afk-engine-v111.jar --output build/unsigned-v111.apk`
4. `python3 patches/sign-v111.py --base-v10 PATH_TO_V10.apk --unsigned build/unsigned-v111.apk --keystore PRIVATE_V10.p12 --password-file PRIVATE_PASSWORD_FILE --agent-jar build/afk-engine-v111.jar --output build/MJLauncher-v1.11-preview.apk`

The GitHub CI tests the host-JVM policy; it does NOT build/sign an APK or guarantee Minecraft compatibility.
