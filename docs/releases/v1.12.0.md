## Rebuild without publishing signing secrets

1. Keep the known-good v1.11.2 APK locally. Do not upload user data.
2. `python3 scripts/prepare-v112.py --base v1.11.2.apk --out unsigned-v112.apk`.
3. Extract the **unchanged** `assets/native-afk/afk-engine-v9.jar` from v1.11.2 as `agent.jar`.
4. Use the repo's `patches/sign-v1111.py` with the existing *private* signing keystore/password to produce the v1.12 APK, e.g. `python3 patches/sign-v1111.py --base-apk v1.11.2.apk --unsigned unsigned-v112.apk --keystore PRIVATE.p12 --password-file PRIVATE.txt --agent-jar agent.jar --output MJLauncher-Modified-v1.12.0-Justicia-H1.apk`.
5. Validate the SHA-256 of the output and the signing cert fingerprint above.

The signed APK exceeds GitHub's 100 MB ordinary git-file limit. Do not commit signing material or split private keys in the repository.
